# RigZen : A Pc Part Picker Webstie           

RigZen is a pc part picker website where users can build and configure their dream pc with 
simple and straigt forward steps this website comes with a build and a compare page where 
you can build and compare the pc parts it also includes a featured build section where the
pc build is made and picked by pc proffesionals and loved by most of the people in the 
community 

You can download the next.js app by 

```bash
npx create-next-app@latest {your_folder_name}
```

You can run the project locally by 

```bash 
npm run dev
```

You can visit the website locally by :- http://localhost:3000/

This project dosent need any external modules needed to be installed
